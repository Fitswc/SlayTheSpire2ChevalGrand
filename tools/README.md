# 卡图工坊

双击 `tools/start_card_art.cmd` 启动本地窗口。需要 Python 3.10+（含 Tkinter）和 Pillow；当前开发环境已具备。其他电脑如缺少 Pillow，在本目录运行 `python -m pip install -r requirements.txt`。也可运行 `python -B tools/card_art.py`。

## 操作

1. 按中文卡名或 C# 类名搜索，选择卡牌；可筛选缺图卡牌。
2. 点击“导入图片”，支持 PNG、JPEG、WebP、BMP、TIFF；或载入所选卡牌的已有图片。处理在本机完成，无需联网。
3. 拖动白色裁剪框移动取景，调整“取景放大”改变取景范围。白框与成图预览保持输出比例；“居中 / 重置”恢复最大居中取景。
4. 选择尺寸预设或输入宽、高（16–4096 像素）。已有卡图默认沿用原尺寸，新卡默认 850×646。这是现有资产中最常见的尺寸，并非已确认的引擎硬性要求；1000×760 也是现有尺寸，两者比例都是 25:19。
5. “导出到 tools/output”用于暂存；“保存到项目卡图目录”直接写入 `ChevalGrandSlay/ChevalGrandSlay/images/cards/<类名>.png`。每次保存只处理当前卡牌。

替换已有文件时必须确认，并先将旧文件备份到 `tools/backups/`。恢复时将备份复制回目标目录并恢复原文件名。原始导入图片不会被修改，除非它本身就是你明确确认替换的目标卡图。

## 范围与限制

- 自动读取项目中的 `ModCardTemplate` 类及中文本地化，忽略备份 `.cs~` 和没有对应类的旧图片。每次启动重新读取卡牌。
- 只对使用当前项目标准 `PortraitPath` 表达式的卡牌启用直接保存。`CGSEmptyShell` 当前没有配置卡图路径，标为“未接入”，可暂存图片，但单独添加图片不会在游戏中显示。程序不会修改卡牌代码。
- 使用原始像素裁剪后高质量缩放，不拉伸变形。自动处理 EXIF 方向，保留透明通道；动态图片只使用第一帧。预览不含游戏卡框、遮罩或文字。
- 原图上限为 4000 万像素；输出超过取景像素时会提示可能模糊。自定义尺寸可改变比例，请按实际需要填写。
- 写入项目卡图目录只在点击对应保存按钮时发生；依赖文件、说明、暂存图和备份都位于 `tools/`。不会主动修改 `.import`、C#、本地化或其他项目文件；后续 Godot 导入和游戏打包仍由原项目流程负责。
- 完整 PNG 先写入临时文件，再发布到目标名称；Windows 下首次保存使用拒绝覆盖已有目标的重命名操作。请避免多个窗口同时替换同一张卡图。

## 验证

在项目根目录运行 `python -B -m unittest discover -s tools -p "test_*.py"`。测试所有临时文件只写入 `tools/`，不替换实际卡图。
