# Powers 中文命名方案

本文件先于本次能力名称写入创建，完整方案已在聊天中以 Markdown 列出。

## 原则与范围

- 有对应卡牌的能力优先与当前卡名一致；独立能力或效果型负面状态按实际作用命名。
- 本次30个能力名全部不超过5个字符，标点计入。对应卡牌的显示名不变。
- 只更新简体中文能力标题及5处卡牌描述中的能力名称引用；能力效果、数值、类名、本地化键、英文版本不变。
- 沿用卡名的取材依据见[第四版卡名资料](card-name-localization-v4.md)。新增措辞是效果命名或主题创作，不冒充官方台词，也不另造原作出处。
